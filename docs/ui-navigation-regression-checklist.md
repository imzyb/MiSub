# 导航 UI 回归检查清单

用于每次发布前快速验证「现代布局 + 经典布局」导航区域是否正常。

## 基础检查

- 品牌 Logo 图标与文案显示正常（顶部与移动端）；点击跳转正确：已登录指向 `/dashboard`，未登录指向 `/`。
- 深色/浅色切换按钮可点击，图标状态正确，无障碍开关状态随主题变化。
- 切换布局按钮可点击，现代/经典布局可来回切换（写入偏好后整页跳回 `/`，刷新后仍保持）。
- 退出登录按钮可点击，能正确回到未登录状态。
- 语言切换按钮可点击，中文/英文即时切换，刷新后仍保持所选语言。
- 公开页开关开启时，登录状态下的现代导航出现「公开页」入口，跳转 `/explore` 正常。
- 未登录访问首页或公开页时出现反馈按钮，点击能打开留言板；留言板关闭时给出提示。
- 配置了自定义登录路径时，登录入口指向该路径；留空或为 `/login` 时使用默认入口。

## 现代布局（吸顶导航）

- 仅登录后且布局偏好为现代布局时使用现代导航；公开页阶段与经典布局不应出现。
- 桌面顶部吸顶导航：当前路由高亮胶囊显示正常，首页、仪表盘精确匹配，其余菜单按前缀匹配。
- 桌面导航链接 hover/active 文案颜色正确。
- 右侧操作按钮圆角/hover/focus ring 一致。
- 移动顶部操作区按钮样式与桌面风格一致。
- 移动底部导航 active 状态与图标缩放正常；未登录时不出现底部导航。
- 切换语言后导航项文案与无障碍标签同步更新。

## 经典布局（顶部头部区）

- 顶部品牌区域与现代布局视觉一致；已登录时 Logo 指向 `/dashboard`，未登录时指向 `/`。
- 已登录：显示设置、切换布局、退出登录。
- 未登录：显示 GitHub 按钮和登录入口；配置自定义登录路径时隐藏登录按钮，开启隐藏品牌时隐藏 GitHub 按钮。
- 公开页伪装：开启隐藏品牌后品牌区退化为「首页」文本链接；开启隐藏头部后整个头部不渲染（仅未登录的公开页生效）。
- iOS 安全区顶部 padding 正常，无状态栏遮挡。

## 交互与可访问性

- 所有图标按钮均有可读 `aria-label`；现代布局的移动顶部、桌面主导航、底部标签栏分别带对应的无障碍标签。
- 键盘可聚焦按钮并看到焦点样式（focus ring），焦点顺序与视觉顺序一致。
- 触屏设备（`pointer: coarse`）下动作按钮最小可点击区域不小于 44px。
- 明暗两种主题下文字与背景对比度足够，链接/按钮在 hover、active、禁用态均清晰可辨。
- 减少动态效果设置（`prefers-reduced-motion`）下无突兀动画。
- 移动端底部导航不遮挡内容与页脚（页脚已预留底部安全区高度）。

## 本地调试专项

- 联调 Pages Functions 用 `npm run dev:server`（`wrangler pages dev public`，默认 8787）；前端开发用 `npm run dev`（Vite，默认 5173）。
- `npm run build` 后用 `npm run preview` 检查构建产物，首页与控制台无初始化错误。
- 控制台无初始化报错。
- 发版后旧页面切入懒加载路由时，分包加载失败应自动重载一次而不是白屏。
- 强刷或清理站点数据后页面仍可正常加载；浏览器禁用站点数据时，布局偏好读取不应阻塞启动（需有容错）。
