# 导航组件架构说明

本文档描述 MiSub 当前导航相关组件的职责拆分，便于后续迭代时避免重复实现和风格漂移。

## 组件分层

- **现代布局导航容器**
    - 仅在已登录且布局偏好为「现代布局」时挂载
    - 桌面端为顶部吸顶横幅，移动端为顶部品牌 / 动作栏
    - 登录后额外挂载移动端底部标签栏；未登录时不渲染底部导航
    - 负责导航项渲染与当前项判定：首页与仪表盘精确匹配，其余按路径前缀匹配
    - 品牌 Logo 固定指向 `/dashboard`；开启公开页时展示公开页入口；公开页伪装开启「隐藏品牌」时隐藏仓库外链
- **经典布局头部容器**
    - 同时承担未登录公开页的头部，负责经典布局下的品牌区与动作区挂载，含 iOS 安全区适配
    - 隐藏品牌时用「首页」文本链接替代 Logo；配置自定义登录路径时隐藏登录按钮
- **品牌标志组件**
    - 图标 + 文案的原子组件，两种布局共用；可配置跳转目标（默认 `/`，登录态由调用方指向 `/dashboard`）、文案与图标尺寸
    - 读取打包内的 Logo 资源，加载失败时降级为内联图标
- **顶部动作区**
    - 组合公开页、反馈、语言切换、主题切换、设置、切换布局、退出登录、GitHub 外链与登录入口
    - 通过开关控制不同场景的显隐：登录态、是否展示公开页入口、是否展示设置、是否展示登录按钮、圆角样式、焦点环、分隔线、是否隐藏仓库外链
    - 公开页反馈按钮仅在未登录且当前位于首页 / 探索页时出现，点击后通知公开页打开留言板
    - 向上通知：打开设置、切换布局、退出登录
- **登录入口按钮**
    - 跳转目标优先取自定义登录路径，否则为 `/login`
- **GitHub 外链按钮**
    - 指向仓库的外部链接入口
- **语言切换按钮**
    - 全站中英切换，语言偏好写入浏览器本地存储
- **主题切换按钮**
    - 明暗主题切换，由顶部动作区挂载，带无障碍开关状态
- **布局组件统一出口**
    - 导航相关组件集中导出，供页面按需引入

## 样式来源

统一使用主样式表里的导航设计令牌：

- 品牌区：品牌图标与文案的尺寸、间距与配色
- 动作按钮：常规态、中性态、危险态，以及统一的焦点环
- 导航链接：普通态、当前项胶囊、激活 / 非激活文字色；移动底栏项与图标容器
- 布局容器：顶部导航（圆角归零）、移动底栏的玻璃层与内层
- 圆角：按统一圆角档位传入，动作区可按场景选择
- iOS 安全区：顶部 / 底部内边距、状态栏覆盖层、固定头部
- 触控目标：粗指针设备下最小 44px、次级 24px，动作按钮同步放大
- 动效降级：系统开启“减少动态效果”时关闭导航动画与过渡

## 配置来源

- 导航菜单与图标：导航项包含翻译 key、中文回退名（不参与渲染）、路径与图标；图标路径由导航项与动作按钮共用
- 导航文案：中英双语文案表，组件按翻译 key 渲染
- 布局偏好：现代 / 经典两种布局，持久化到本地；切换后跳转首页，以整页刷新完成布局切换
- 公开页与伪装：是否展示公开页入口、自定义登录路径、公开页伪装开关（启用 / 隐藏品牌 / 隐藏头部 / 隐藏底部）
- 路由名称：首页与探索页，用于判定公开页反馈按钮是否出现

## 使用建议

- 新增导航项时，同步更新导航菜单、图标与中英文案，不要只写死中文回退名。
- 新增导航动作时，优先扩展动作区组件，用开关控制显隐，不要在容器组件里直接堆按钮。
- 修改品牌视觉时，优先改品牌标志组件与品牌设计令牌。
- 修改 hover / focus / active 交互时，优先改主样式表里的对应令牌，并沿用统一焦点环。
- 避免在两种布局容器里各写一套样式，保持两种布局一致。
- 新增图标按钮必须带可翻译的无障碍标签，并确认在触屏设备上点击区域不小于 44px。
- 调整布局挂载条件时，在应用根组件统一判断，不要在容器组件内部判断。
