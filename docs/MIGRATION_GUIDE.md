# MiSub 架构升级：从“净化管道”到“操作符链”

为了实现更高自由度的节点处理，MiSub 在 v2.5.0 版本中将原有的固化“净化管道”彻底重构为灵活的“操作符链”。

如果您是老用户，请参考此文档完成平滑迁移。当前仓库版本为 **v2.8.0**；本文按当前版本的实际行为整理。

---

## 1. 我们的兼容性承诺：Legacy Bridge

**不必担心损坏！** 即使您不进行任何操作，MiSub 后端也内置了 **Legacy Bridge (旧版桥接层)**，会在运行时把旧版配置转换成操作符来执行。

- 只有在订阅组没有自己的操作符链、没有旧版转换字段，且全局默认操作符链也为空时，桥接层才会把旧版配置动态转换成操作符执行。
- 桥接映射范围：过滤器（包含 / 排除 / 协议 / 地区）、正则重命名、模板重命名、去重、排序。
- 桥接是运行时适配，不改写您的存储数据；您的链接依然有效。

> [!WARNING]
> 有两类旧版能力**没有等价的桥接**，迁移前请先确认：
>
> - 旧版「脚本过滤」与「精简模式」：过滤操作符只提供正则、协议、地区三类条件，这两项在桥接后会被忽略，迁移时也会提示“未迁移”。
> - 旧版「远程脚本 URL」：脚本操作符只接受受限 DSL，不再下载或执行任何远程脚本。
>
> 旧版「改名脚本」不需要您手动改写：一键迁移会把它转换成等价的受限 DSL 改名步骤。
>
> 如果依赖上述能力，请按第 3 节手动重建为“过滤节点”的正则条件或受限 DSL 步骤。

## 2. 推荐方案：一键迁移工具

虽然有桥接层，但仍建议您完成迁移，把配置固化成新格式。

### 迁移步骤：

1. **进入编辑界面**：设置 → 全局设置（“数据与集成”分组）→「默认转换操作符链」卡片。
2. **识别提示卡片**：仅当这条链当前为空、且存在已启用的旧版配置时，操作符编辑器上方才会出现**橙色提示卡片**：“发现旧版配置”。
3. **点击“立即迁移”**：会把旧配置（过滤器、正则重命名、模板重命名、改名脚本、去重、排序）即时转换成一组操作符。其中旧版「改名脚本」会转换成等价的受限 DSL 改名步骤；旧版「脚本过滤」「精简模式」没有等价操作符，迁移时会提示“部分项目未迁移”。
4. **保存**：检查生成的链后保存设置。

> [!IMPORTANT]
>
> - 迁移卡片只在“全局设置”出现；订阅组编辑弹窗里的操作符链不读取旧配置，订阅组级的旧配置请手动重建，或继续依赖桥接层。
> - 迁移只生成操作符配置，不改动历史链接；旧配置字段仍保留在存储中，但只要有操作符链生效就不再参与处理。
> - 迁移后请查看提示里列出的“未迁移”项，用“过滤节点”的对应条件或受限 DSL 步骤手动补齐。
> - 旧版配置的编辑界面已移除，后续请在「默认转换操作符链」里维护规则。

## 3. 手动映射逻辑对比

如果您想手动重建管道，可以参考下表：

| 旧版功能项              | 对应操作符类型                      | 现状与备注                                                                                                                    |
| :---------------------- | :---------------------------------- | :---------------------------------------------------------------------------------------------------------------------------- |
| **包含/排除关键词**     | `过滤节点 (Filter)` → 包含/排除正则 | 两项可同时启用，先包含后排除；正则默认忽略大小写，多条规则之间为“或”                                                          |
| **协议/地区勾选**       | `过滤节点 (Filter)` → 协议/地区限制 | 协议从常用标签点选；地区按中文地区名或 ISO 地区代码匹配                                                                       |
| **正则重命名**          | `正则命名 (Rename)` → 正则替换      | 默认忽略大小写并替换全部匹配；替换文本中可直接引用 `{regionZh}` 等变量                                                        |
| **模板重命名**          | `正则命名 (Rename)` → 模板重写      | 占位符 `{emoji}` `{regionZh}` `{region}` `{protocol}` `{name}` `{server}` `{port}` `{index}` `{index:2}` `{g1}`；可设起步索引 |
| **改名脚本**            | `脚本执行 (Script)` → DSL 改名步骤  | 一键迁移会转换成等价的受限 DSL 改名步骤；受限 DSL 不执行任意 JavaScript                                                       |
| **脚本过滤 / 精简模式** | 无对应操作符                        | 桥接层会丢弃，迁移时会提示“未迁移”；需要时用“过滤节点”的正则、协议、地区条件重建                                              |
| **排序 (Sort)**         | `节点排序 (Sort)`                   | 支持地区、协议、名称、正则置顶、自定义分组、服务器、端口多键排序                                                              |
| **去重 (Dedup)**        | `智能去重 (Dedup)`                  | 可按“服务器 + 端口”或“完整链接”；同一去重键下保留名称更长的一条                                                               |

## 4. 常见问题排查

**Q: 迁移后节点名称变了？**
A: 模板重写的 `{index}` 默认按“地区”分组自增（旧版默认按“地区 + 协议”分组），因此编号可能不同；编号取当前链内顺序，若希望结果稳定，建议在模板重写前加一个“节点排序”操作符，或用 `{index:2}` 补零格式。正则捕获组 `{g1}` 等未匹配时会留空。

**Q: 过滤逻辑失效了？**
A: 先确认“过滤节点”操作符本身处于启用状态（卡片上没有“已暂停”标记），再确认对应条件已打开（“协议限制 / 地区限制 / 包含正则 / 排除正则”显示“已开启”），并检查正则写法。正则默认忽略大小写，不需要额外设置标志。

**Q: 我发现有些老功能在操作符里找不到？**
A: “脚本过滤”和“精简模式”已经没有对应操作符，迁移时会提示未迁移；“脚本执行”只接受受限 DSL，不支持任意 JavaScript，也不再下载执行远程脚本。强需求请改用“过滤节点”的正则条件，或参照《操作符链完全指南》第 3 节编写 DSL 步骤。

**Q: 迁移按钮不出现？**
A: 只有「全局设置 → 默认转换操作符链」里当前链为空、且旧版配置处于启用状态时才会出现；订阅组里的操作符链没有迁移入口。

## 5. v2.5.0 之后的版本现状（截至 v2.8.0）

- **执行位置**：订阅输出链接（`/sub/*`）、订阅组预览、机场订阅的节点持久化写库，三处共用同一套操作符链。
- **优先级**：订阅组自己的操作符链 → 订阅组的旧版转换字段 → 全局默认操作符链 → 旧版配置桥接；单机场订阅则是：该订阅自己配置的操作符链 → 它的旧版转换字段，之后才应用该订阅的文本规则与订阅组 / 全局的包含 / 排除过滤。
- **2.7 起的新能力**：排序新增“正则置顶”与更多排序键（自定义分组 / 服务器 / 端口）；去重可选“完整链接”；操作符编辑器文案已随站点中英双语切换。
- **其他迁移背景**：订阅组对外链接改用独立的系统标识——存量订阅组会自动补齐标识（补成原 ID），旧链接不断；设置自定义 ID 后该订阅组的系统标识退役、不可再访问。细节见 [profile-url.md](profile-url.md)。
